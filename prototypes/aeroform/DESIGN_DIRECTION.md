# AeroGraph Visual Direction

## Locked foundation

- **Environment:** Dark is the primary environment, not an optional mode.
- **Signature form:** A persistent Cloud combines atmospheric mass with selectively resolved graph structure.
- **Viewpoint:** The visitor follows a tangential orbital path. The Cloud remains partly offscreen so its scale exceeds the viewport.
- **Material:** Soft liquid volume carries sparse directional chrome highlights. Most particles establish depth; only a minority behave as glints.
- **Color family:** Petrol anchors the system: black-green depth, oxidized green, mint interference, chrome, and a restrained amber index.
- **Logo image:** The optical ellipse uses the same petrol material family while retaining enough chrome and warm refraction to remain distinct from the Cloud.
- **Information hierarchy:** Ambient topology stays subdued. The active neighborhood receives the strongest contrast and chroma.
- **Motion:** Movement communicates traversal and velocity. The environment remains still when the visitor is not interacting.

## Open calibration

- Petrol intensity remains adjustable between restrained, balanced, and charged treatments. Balanced is the working default.
- The final wordmark typeface remains open. Slight Chance Mono is a candidate, but the exact face requires a licensed font asset for evaluation.
- Production rendering technology and adaptive quality levels remain implementation decisions.

## Near-term website scope

The first hosted site can use this foundation without completing a comprehensive brand system. It needs:

1. The orbital Cloud as its primary visual.
2. A concise explanation of AeroGraph.
3. A link to the source repository.
4. Responsive and reduced-motion behavior.
5. A static visual fallback for constrained devices.

The design lab is an evaluation tool. Its controls, telemetry, and interface chrome are not the website navigation system.
